# Commands

To add submodules:

```shell
git submodule add -b feature/tool aelf:aevatarAI/aevatar-station.git aevatar-station
git submodule add -b feature/tool-workflow aelf:aevatarAI/aevatar-gagents aevatar-gagents 
git submodule add -b feature/tool aelf:aevatarAI/aevatar-workshop aevatar-workshop 
```
